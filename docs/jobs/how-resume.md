# 怎么写求职简历
`更新-260716` \| `发布-260716`

本文简历主要涉及以下相关的几种：

- **找工作简历**。写一个简历，去应聘校招岗位，最终入职用人单位，成为正式员工。
- **找实习简历**。写一个简历，去应聘实习岗位，最终成为用人单位的实习生。
- **研究生简历**。写一个简历，和导师/学院接洽，最终被录用读研究生。

找工作简历，和找实习简历，相对比较类似。很多用人单位的实习生，可以转为正式员工。也有纯粹实习的岗位，实习结束就结束了。

研究生简历，和上述2个简历的内容，应该有所不同。

请同学们思考如下基本问题：

1. 写出一份非常有针对性的简历，是为了达成什么目的？
2. 根据要达成的目的，简历要呈现哪些内容？
3. 个人的简历，和岗位（以及研究生）的要求，有这样那样的差距，后续该采取什么行动？

## e1-先写一份简历

针对某个岗位（或者研究生），先写一份简历。

**1、关于简历篇幅**

- 找工作简历：建议不超过 1 页 A4 纸张
- 找实习简历：建议不超过 1 页 A4 纸张
- 研究生简历：建议不超过 1 页 A4 纸张？

**2、关于岗位要求**

- 搜索历史校招信息。可参考 [26年校招信息↗]
- 搜索“国家大学生就业服务平台”。可参考 [ncss使用指南↗]
- 搜索微信公众号“江南大学智慧就业”
- 访问心仪用人单位的招聘官网
- ……

**3、建议**

- 重点关注个人简历的内容。样式和版式，后续再调优。
- Word / WPS / PowerPoint / VSCode / Notepad / ……，哪个顺手就用哪个

写好后，可以和老师一起商讨，或者和同学商讨。
