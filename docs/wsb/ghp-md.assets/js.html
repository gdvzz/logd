什么是 JavaScript？

JavaScript 是 Web 的动态脚本语言，为网页赋予交互、逻辑和数据处理能力，是 Web 应用的核心驱动。

本页源码说明

JavaScript 代码实现了两个功能：

  • 主题切换 — 点击开关切换 body 的 dark class，CSS 自动响应
