什么是 HTML5？

HTML5 是超文本标记语言的第五次重大修订，提供了丰富的语义标签，如 header、footer、article、section、aside、nav、main 等，让页面结构清晰，利于 SEO 和可访问性。

本页源码说明

这个页面完全使用语义标签构建，没有使用 div 或 span。每个区块左上角的蓝色小标签标注了对应的 HTML 标签名称。

完整源码结构


<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>HTML5 简介</title>
    <link rel="stylesheet" href="style.css" />
</head>
<body>
    <header> 页眉区域 </header>
    <nav> 导航链接 </nav>
    <main>
        <section>
            <article> 主文章内容 </article>
        </section>
        <aside> 侧边栏信息 </aside>
    </main>
    <footer> 页脚 </footer>
</body>
</html>

核心标签

  • header — 页面头部
  • nav — 导航区域
  • main — 核心内容（页面唯一）
  • section — 内容分组
  • article — 独立内容块
  • aside — 侧边辅助
  • footer — 页脚
