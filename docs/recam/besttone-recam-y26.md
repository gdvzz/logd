## AI开发工程师
`号百公司` \| `上海市`

**学历要求：**
- 本科及以上

**专业要求：**
- 计算机科学、人工智能、数据科学、电子工程等相关专业

**岗位职责：**
1. 参与AI项目的设计与开发；
2. 参与数据处理与分析，协助数据收集、清洗和预处理，进行数据特征提取和分析，为模型训练提供高质量的数据支持；
3. 参与完成AI模型的训练和调优，进行模型的验证和测试；
4. 按照团队规范编写代码和相关技术文档；
5. 协助解决AI项目中的技术问题，参与技术讨论和分享；
6. 持续学习AI领域的最新技术和工具，探索和引入新的AI技术，推动团队技术创新和应用。

**任职资格：**
1. 2026年毕业，本科及以上学历、学士及以上学位的应届毕业生，计算机科学、人工智能、数据科学、电子工程等相关专业;
2. 熟悉至少一种编程语言（如Python、C++、Java），具备良好的编程能力和代码风格;
3. 熟悉机器学习和深度学习的基本原理，了解常用算法（如分类、回归、神经网络等）;
4. 熟悉至少一种主流的AI框架（如TensorFlow、PyTorch、Keras等），能够进行模型训练和调优。
5. 了解数据处理和分析的基本方法，具备一定的数据预处理和特征工程能力。
6. 良好的沟通和团队合作、逻辑思维，主动的学习意愿和较强的学习能力，认真负责的工作态度，能承受较大的工作压力。

## Java开发工程师
`号百公司` \| `上海市`

**学历要求：**
- 本科及以上

**专业要求：**
- 计算机等相关专业

**岗位职责：**
1. 负责5G消息应用等核心业务模块设计与研发工作；
2. 承接平台核心代码的编写，运营迭代；
3. 攻坚克难技术问题、优化系统性能；
4. 保障系统的安全、稳定、快速运行，解决开发过程中和线上的各种技术问题；
5. 跟踪前沿技术、并搭建测试系统快速验证等。

**任职资格：**
1. 2026年毕业，本科及以上学历、学士及以上学位的应届毕业生，计算机及相关专业；
2. 有扎实的Java基础和面向对象编程，熟悉Spring, springcloud全家桶、Mybatis,Hibernate等常用的开源框架,了解微服务架构和设计模式，熟悉分布式系统原理；
3. 熟悉互联网常用技术和中间件、消息中间件、分布式框架；熟悉Linux操作系统，熟悉Tomcat、Nginx，熟悉MySQL；
4. 具备良好的设计通用框架及模块能力；
5. 具备良好的理解能力、表达能力和合作意识，对待工作认真负责、积极主动。
