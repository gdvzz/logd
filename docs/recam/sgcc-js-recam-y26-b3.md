**江苏电力信息技术有限公司** 简介如下：

江苏电力信息技术有限公司位于江苏省南京市，成立于2000年。公司主要从事软件开发、技术支持、信息系统运行维护、系统集成等业务。

公司是国家级专精特新“小巨人”企业，设有江苏省研究生工作站、江苏省软件技术中心、南京市工程研究中心，牵头组建江苏省新型电网安全态势感知产业技术工程化中心、南京市电力人工智能创新联合体，是国网系统首个通过国际软件成熟度（CMMI5）评估、省公司系统首个获得信息技术服务标准ITSS二级资质的单位。

作为电力行业数字化服务提供商，聚焦新型电力系统建设与数字化转型，相关产品和服务广泛应用于各专业领域，着力打造“苏电AI”人工智能品牌、“电力看”大数据品牌、苏电AI物资评标大模型、AI输电网络隐患预警及处置系统、AI供指等核心产品，形成了8大板块100余款的产品体系，是支撑电力数字化建设的主要力量，是颇具规模与影响力的行业领先企业。
