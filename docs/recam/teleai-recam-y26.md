    中电信人工智能科技有限公司（以下简称“人工智能公司”）成立于2023年8月，是中国电信开展人工智能业务的科技型、能力型、平台型专业公司。依托中国电信强大的云网融合能力、海量自有数据及丰富应用场景优势，打造了从数据、算法到应用的全栈Al能力，全面支撑AI规模化发展。

    人工智能公司深耕人工智能核心技术，在Al大模型、Al中台、大数据等关键领域实现突破，构建了层次分明的标准化能力、软硬件一体化服务、行业解决方案、开发开放平台等产品体系。通过自主研发与生态合作相结合，公司推动Al技术与产业场景深度融合，已在政务、公安、工业、教育等多个领域实现规模化应用落地，新质生产力赋能千行百业。

    中国电信人工智能研究院（TeleAI）由中国电信集团CTO、首席科学家李学龙教授牵头组建，于2024年7月正式揭牌。结合中国电信在算力、数据、应用场景及通信等多方面优势，TeleAI形成聚焦Al治理、智传网（AI Flow）、智能光电（包括具身智能）、智能体的“一治+三智”科研布局，目标打通并发展由Al驱动的“三大空间经济”，全面覆盖赛博空间、临地空间、广域空间，拓展人类的认知和活动边界。

    TeleAI旨在打造人工智能研发与产业转化的标杆平台，通过跨学科跨领域协同创新，汇聚顶尖人才和团队，形成产学研用一体化创新生态，以人工智能新质生产力赋能千行百业，以科技创新引领现代化产业体系建设。

## 双臂操作算法研究员/研究工程师
`人工智能研究院` \| `上海市-徐汇区`

**学历要求：**
- 硕士研究生及以上

**岗位职责：**
1. 负责双臂协同/灵巧操作/真机强化学习等算法研发和前沿技术的研究，进行算法功能开发和优化;
2. 负责sim2real工作，对所需机器人算法进行仿真训练，能够验证和部署至实际场景中;
3. 负责构建大规模高质量数据集，构建从包括Egocentric数据/遥操作数据/动捕数据/UMI/仿真结合的数据金字塔方案，支撑模型训练。

**任职资格：**
1. 计算机科学、机械工程、人工智能相关领域的研究生以上学位。
2. 熟悉NVIDlA lsaac，V-Rep、Gazebo、MuJoCo、PyBullet等仿真软件，且掌握运动学和动力学建模的基本方法;
3. 了解双臂机器人和灵巧手平台操作算法，有深度学习、模仿学习、强化学习、最优控制基础等方向的基础，有仿真环境搭建、6D抓取位姿估计、模仿学习、视觉Affordance识别、sim-to-real等方面的开发和研究经验。
4. 在深度学习 / 多模态学习 / 计算机视觉 / 具身智能等相关领域的国际期刊或会议上有发表论文者优先。
