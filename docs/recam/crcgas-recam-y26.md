4. 项目支撑与业务赋能：协助信息化新项目、新系统的需求调研、测试上线、培训复盘全流程落地；对接各部门信息化基础需求，提供操作指导与技术支持，协助提升各部门数字化办公能力；

**【任职条件】**

1. 全日制本科及以上学历应届毕业生，信息管理与信息系统、计算机科学与技术、网络工程、大数据管理与应用等信息技术相关专业；
2. 熟练应用Office等办公软件，掌握信息化系统、数据库基础操作技能，了解数据分析、数字化转型相关知识者优先；具有高度责任心、团队合作意识与良好的职业操守，具备优秀的学习能力、沟通协调与问题解决能力。
