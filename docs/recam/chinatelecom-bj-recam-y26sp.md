## IT研发工程师
`省本部` \| `北京市`

**学历要求：**
- 硕士研究生及以上

**专业要求：**
- 计算机类、信息安全类、软件工程类、电子信息类、通信类、​数学类、大数据类、人工智能类、自动化类等专业优先

**岗位职责：**
1. 大模型微调与优化： 负责对选定的大模型进行领域适配与精调，设计构建高质量训练数据集，实施优化微调策略（如Prompt Tuning, LoRA等），持续评估模型性能（准确率、推理速度等）并迭代优化，探索前沿微调技术以提升效果与效率；
2. 大模型应用开发： 基于微调模型或通用API，设计开发端到端AI应用（Web/API/集成）；精通Prompt Engineering设计高效提示；构建稳定后端服务与友好前端交互；关注性能、成本优化，确保解决方案高效落地；
3. 新技术学习与应用： 持续追踪大模型、生成式AI、Agent等领域前沿技术与工具（如LangChain, LlamaIndex）；主动研究评估其应用价值并进行技术预研与原型验证；快速将有效技术引入实际项目，推动团队技术升级；参与内部分享；
4. 智能体开发： 设计开发基于大模型的智能体，实现规划、工具调用、记忆、交互等能力；构建核心模块（规划器、记忆、工具集）；利用框架（如LangChain Agents）或自研实现单/多智能体系统；测试评估智能体性能、可靠性并持续优化；
5. 对接业务需求： 深入理解内外部业务场景与痛点，沟通转化需求为技术方案；评估方案可行性、工作量与风险；参与项目规划与管理；及时同步进展与挑战；跟踪上线效果、收集反馈，驱动方案持续改进，确保技术有效解决业务问题。

**任职资格：**

技术核心：
1. 精通 Python，熟悉 PyTorch/TensorFlow 及 Hugging Face Transformers。
2. 具备大模型微调实战经验 (熟悉主流方法如 LoRA)。
3. 有大模型应用开发经验 (熟悉 Prompt Engineering 及 Flask/FastAPI 等后端开发)。
4. 有智能体开发经验 (熟悉 LangChain 等主流框架)。

工程基础： 
1. 熟悉 Git、Linux 及基本部署流程 (如 Docker)。

关键素质：
1. 极强的技术热情和学习能力，能快速跟进大模型、Agent 等前沿技术。
2. 良好的问题解决、沟通协作能力，能理解并对接业务需求。

加分项：
1. 有成功落地的大模型应用/智能体项目。
2. 熟悉 RAG、多模态模型、模型优化部署。
3. 有 AI 领域论文发表或竞赛获奖。
4. 优秀的技术文档能力。

- 对接业务系统、经分系统等IT系统，提取与校验数据。
- 推动数据可视化、自动化分析，提升分析效率。
4. 经营考核与绩效支撑
- 支撑绩效考核、KPI 分解、对标分析、通报预警。

- 熟练使用 Excel（数据透视表、函数、图表），会 SQL、BI 工具（如 Tableau/Power BI、SPSS）优先。
- 了解移动通信、宽带、云、数据中心、AI、大数据等电信业务基本知识。
3. 能力素质
- 细心严谨、责任心强，能承受报表周期、预算季等阶段性加班。
- 沟通协调能力强，能跨部门推进工作。
- 学习能力强，能快速理解运营商业务规则与指标体系。

- 有运营商、通信行业、大型集团经营分析 / 预算 / 财务分析实习经验优先。
- 有全面预算编制、经营预测、KPI 考核、数据分析项目经验优先。
