1. 通信网络、计算机、人工智能、电子信息、软件工程、多媒体技术相关专业，博士学历；
2. 精通流媒体全栈技术，包括但不限于 RTMP、HTTP-FLV、HLS、DASH、SRT、RTP/RTCP、WebRTC 等传输协议，熟练掌握 H.264/H.265/H.266、AVS2/AVS3、VP9 等编解码标准，具备超高清、4K/8K、低时延流媒体架构设计与优化经验；
3. 精通流媒体分发、转码集群、媒体服务器、CDN、边缘节点调度架构，具备百万级以上高并发流媒体平台架构设计、建设与优化实战经验；
4. 具备独立完成端到端流媒体技术方案规划、制定与落地能力，熟悉云网融合、广域网 / 城域网媒体传输架构，掌握 K8s、容器化、SD-WAN、边缘计算等技术在流媒体场景的应用；
