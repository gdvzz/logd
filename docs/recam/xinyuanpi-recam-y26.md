## 平台运营工程师
`信元公司` \| `北京市`

**学历要求：**
- 硕士研究生及以上

**专业要求：**
- 计算机、软件工程、通信工程、信息管理与信息系统等相关专业

**岗位职责：**
1. 负责业平台的全生命周期运营，建立平台运营体系与规范，通过技术与数字化手段提升平台运行效率与稳定性，为业务运营提供核心支撑保障。
2. 负责业务平台的性能优化、迭代规划与质量管控，开展平台运行风险排查与服务能力评估，结合业务发展需求输出优化方案并推动落地，持续提升平台服务品质与用户体验。
3. 负责业务平台的运行安全管理，开展平台运行安全的风险评估与应急事件处置，制定并落地应急预案与重要保障方案，保障平台业务安全运行。
4. 负责对接业务与客户需求，输出平台运营分析报告与数字化解决方案，推动平台能力与业务需求深度匹配，助力业务价值持续提升。

**任职资格：**
1. 硕士及以上学历，计算机、软件工程、通信工程、信息管理与信息系统等相关专业
2. 熟练掌握计算机网络、操作系统、数据库、云计算等IT领域基础理论，熟悉业务平台的技术框架。
3. 熟悉DevOps理念，精通Python等开发工具，具备Ansible、Prometheus、Kubernetes等工具的实际使用经验优先。
4. 熟悉运维领域大模型的基本原理与典型应用场景，了解大模型在故障根因分析、智能告警降噪、自动化运维脚本生成、运维知识问答等场景的落地方案。

## 信息安全工程师
`信元公司` \| `北京市`

**学历要求：**
- 硕士研究生及以上

**专业要求：**
- 计算机、数据科学、统计学、信息安全等相关专业

**岗位职责：**
1. 负责模型全生命周期管理与效能提升。搭建并完善反诈模型（如涉诈号码识别）的实时监控体系，通过数据分析快速定位模型偏差与业务漏洞，驱动问题高效解决。负责评估与迭代，构建多维度的模型评估矩阵（涵盖召回率、精确率、误杀率及拦截率等），定期输出复盘报告，并协同算法团队完成从问题发现到策略调优的闭环迭代，平衡风控效果与用户体验。
2. 负责智能交互策略与数据资产运营。负责外呼策略优化，主导AI外呼全流程的策略运营，基于用户画像与交互数据设计差异化的外呼剧本，建立覆盖“触达-交互-转化”全链路的效能评估体系，持续提升接通率、交互深度及劝阻成功率。负责反诈语料库的建设与治理，追踪最新诈骗手法及话术演进趋势，组织迭代AI外呼话术模板及文本标注规范，确保反诈引擎的语义理解与打击能力始终领先一步。
3. 负责专项治理与跨域协同。牵头跨部门资源整合，针对高发诈骗类型或重点区域开展专项治理行动，确保技术策略与业务执行的高效落地。建立与省分公司及业务侧的高效对接机制，快速响应一线需求及突发涉诈事件，协同各方完成紧急策略的下发与风险处置。

**任职资格：**
1. 硕士及以上学历，计算机、数学、统计学、通信工程或相关理工科专业。
2. 熟练掌握SQL，熟练使用Python进行数据分析（如Pandas、NumPy），具备数据清洗、特征工程及可视化的实际项目/竞赛经验。熟悉常见的机器学习算法（如逻辑回归、决策树、XGBoost等），了解模型评估指标（召回率、精确率、AUC等）的实际含义及应用场景。
3. 具备优秀的结构化思考能力，能够基于有限数据快速定位问题核心，并通过逻辑推导提出可行的验证方案。
对数据敏感，善于从数据波动中洞察业务异常，有通过数据驱动业务决策的校园项目或实习经验者优先。
4. 具备快速学习能力，对黑灰产对抗、反诈技术有兴趣，能适应互联网快速变化的节奏，具备应急响应所需的抗压能力和责任心。
5. 具备良好的文档撰写能力和跨团队沟通意识。

## 数据开发工程师
`信元公司` \| `北京市`

**学历要求：**
- 硕士研究生及以上

**专业要求：**
- 计算机、软件工程、大数据、人工智能等相关专业

**岗位职责：**
1. 负责大数据平台开发与维护工作，参与大数据平台（如Hadoop、Spark、Flink、Doris等）的搭建与优化，支持数据采集、存储、处理及分析任务；开发ETL流程，构建数据仓库模型，实现数据清洗、转换与加载。
2. 负责数据应用开发，基于业务需求开发数据报表、可视化工具（如ECharts、Tableau）或数据服务接口；协助解决数据建模、分析中的技术问题，提升系统稳定性和用户体验。
3. 参与AI算法相关数据处理工作，包括特征提取、样本构造及数据标注质量控制，推进高质量数据集建设，保障算法模型的训练与推理所需数据的准确性与时效性。
4. 承担平台架构优化、性能调优及技术实现任务，参与技术选型、代码开发及故障定位排查，配合团队完成跨平台的技术集成与升级。

**任职资格：**
1. 硕士及以上学历，计算机、软件工程、大数据、人工智能等相关专业
2. 熟练使用Java及scala开发语言，熟练掌握Hadoop、Storm、Spark、Flink、Doris等大数据生态组件，了解组件原理及适用场景。
3. 了解Hive、HBase仓库设计，理解MR运行原理和机制。
4. 具备AI数据处理与特征工程能力，熟悉高质量数据集构建，能够完成样本构造、数据标注质量控制及特征提取，保障模型训练数据的高效准确。
5. 具备一定的应用系统分析与设计能力，熟悉平台架构优化与技术选型工作，掌握平台开发相关技能，包括Linux常用命令、Apache/Nginx/Tomcat等应用服务器的使用，有良好、规范的编程习惯和文档编写习惯。

## AI算法工程师
`信元公司` \| `北京市`

**学历要求：**
- 硕士研究生及以上

**专业要求：**
- 计算机、软件工程、大数据、人工智能等相关专业

**岗位职责：**
1. 负责业务领域内AI应用场景的探索研究，重点关注大模型（LLM）及多模态技术的应用潜力，熟悉知识库、智能问答、数字员工相关技术和架构，协助团队基于前沿AI技术助力业务智惠转型升级。
2. 负责反诈、客服、信息安全、新通信、号卡终端等领域的AI应用及能力的落地实施工作，结合大模型技术优化智能交互与识别能力，完成相关平台的建设及版本的迭代开发工作。
3. 参与数据开发相关工作，包括数据清洗、转换、特征工程及数据仓库模型优化，确保算法输入数据的高质量与一致性。
4. 承担平台架构优化、性能调优及技术实现任务，参与技术选型、算法模块代码开发及线上问题定位修复，推动 AI 能力与现有业务平台的深度融合。

**任职资格：**
1. 硕士及以上学历，计算机、软件工程、大数据、人工智能等相关专业
2. 熟练使用Java及Python语言开发，具备扎实的AI技术知识体系，熟悉主流AI框架及算法。
3. 具备AI算法设计能力，熟练使用至少一种主流深度学习框架（如PyTorch、TensorFlow等），熟悉至少一种大模型应用开发相关工具链（如LangChain、Dify等）及RAG相关技术，了解模型微调、推理加速等流程。具备一定人工智能开发相关工作经验，了解AI大模型从设计到落地过程中的相关知识，能够进行模型训练、调优及部署等相关工作。
4. 具备数据开发相关能力，熟悉高质量数据集构建，具备数据清洗、转换、特征工程及数据仓库模型优化相关能力。
5. 具备平台架构设计、优化与技术选型能力，掌握平台开发相关技能，包括Linux常用命令、应用服务器部署与性能分析等。
