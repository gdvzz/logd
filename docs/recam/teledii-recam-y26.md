## 网络工程师
`中电信数智科技有限公司（集成公司）` \| `北京市`

**学历要求：**
- 硕士研究生及以上

**专业要求：**
- 计算机、电子信息、软件工程等相关专业

**岗位职责：**
1. 负责电信网络架构设计、网络规划、建设交付，并持续优化；
2. 组织编制网络系统技术方案、实施方案及测试方案；
3. 独立完成网络系统割接及排障工作；
4. 负责客户技术交流及技术培训工作；
5. 配合相关部门完成售前支撑工作。

**任职资格：**
1. 熟悉主流厂家（思科、华为）的路由器、交换机、防火墙等相关设备；
2. 掌握基本网络通信对应的相关原理知识，了解数据通信、光传输、云计算等其中一个领域基本知识；
3. 具有良好的沟通能力和团队精神，能承受较大的工作压力，富有挑战精神；
4. 优秀的学习能力，出色的沟通能力，较强的分析和解决复杂网络问题能力。

3. 熟练掌握Office等办公软件，如Word、Excel、PowerPoint等，具备文档编辑、数据分析和演示汇报能力。
4. 工作认真负责，具备较强的责任心和敬业精神，对新技术有好奇心和探索精神。
5. 加分项：熟悉主流 AI 模型架构（如 GPT 系列、BERT、Transformer 等），了解模型训练、微调及部署流程；掌握 Python 编程语言，了解 SQL 数据库基础操作。

4. 有强烈的进取心和工作激情，勇于接受挑战，善于开拓创新，目标导向，自我驱动。
5. 有产品实习经历或独立设计过产品优先。

- 硕士研究生及以上

**专业要求：**
- 人工智能、智能科学与技术 计算机、电子信息、自动化、数学、物理等相关专业

**岗位职责：**
1. 负责AI相关模型（如NLP/CV/多模态）的研发、调优与迭代，参与核心业务场景的技术方案落地；
2. 负责数据的清洗、预处理与特征工程，构建高质量的数据集以支持模型训练；
3. 跟踪学术界和工业界最新的AI研究成果（如Transformer、Diffusion Models等），并将其快速应用于实际业务中进行实验和验证；

1. 具有良好的计算机基础知识；
2. 在自然语言处理、计算机视觉、深度学习等一个或多个领域有深入等研究，具备扎实的变成技术，有大模型公司实习经验者优先，学习能力强。
