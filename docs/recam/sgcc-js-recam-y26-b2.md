招聘公告摘录如下：

### 一、公司简介

国网江苏省电力有限公司（以下简称"国网江苏电力"）是国家电网有限公司（以下简称"国网公司"）系统规模最大的省级电网公司之一，服务全省5000多万电力客户，拥有35千伏及以上变电站3300余座、输电线路超11万公里，建成了"一交四直"特高压混联、"七纵七横"500千伏输电网的坚强网架，"获得电力"水平全国领先，客户满意率保持99%以上，获评全国用户满意五星级企业、国资委国有重点企业管理标杆企业等荣誉称号，为"强富美高"新江苏现代化建设提供了坚强电力保障。

公司现有13个市、59个县（市、区）供电公司，主要为属地电力客户提供供电服务业务，17个科研、检修、施工业务单位，主要开展科研、通信、建设等支撑业务；72个市、县（区）三新供电服务公司，主要开展乡镇地区供电服务业务。

本批次国网江苏电力招聘单位为：

1. 供电公司及业务单位。
2. 三新供电服务公司。

### 二、需求信息和基本条件

3. 相关说明

    （1）招聘专业均指主修专业，不包含辅修专业及第二学位。

    （2）最终招聘数量将根据应聘人数、公司发展需要及上级单位核准情况相应调整。

**（二）基本条件**

1. 应聘毕业生应具有良好的思想品德和道德素质，遵守国家法律法规和学校规章制度，遵守社会公德，无刑事犯罪和违反校纪校规记录。

2. 应聘的境内院校学生必须是国家统招计划内普通高等院校2026年应届本科及以上学历毕业，**具体招聘专业见需求信息**。本科阶段所学专业应与研究生阶段相同或相近，或为公司所需的专业。

3. 应聘的国（境）外留学生一般应于2025年7月1日至2026年6月30日期间毕业，并于2026年8月31日前取得国家教育行政部门确认的硕士及以上学历认证证书。供电公司及业务单位招聘专业为电工类、财会类、计算机类、通信类；三新供电服务公司招聘专业为电工类、计算机类、通信类。本科阶段所学专业应与研究生阶段相同或相近，或为公司所需的专业。

4. 大学本科生一般应为2001年7月1日及以后出生，硕士研究生一般应为1998年7月1日及以后出生，博士研究生一般应为1993年7月1日及以后出生。退役军人以及条件特别优秀的应聘毕业生，年龄可适当放宽。

5. 应聘毕业生应身心健康，体检合格（体检以国家公务员录用体检通用标准为基本标准），且符合电力企业一线岗位工作要求。患有以下疾病者，不符合公司招聘岗位要求：（1）有恐高症、严重心血管疾病、辨色力不正常等，不适合电力登高等作业生产，无法保障人身和电网设备安全等相关情况；（2）其他经指定医疗机构鉴定认为不适合电力作业的情况。体检不合格的应聘毕业生，招聘方有权取消其应聘及录取资格。

### 三、招聘程序

**（一）发布招聘公告**

根据国网公司统一要求，国网江苏电力于2026年2月25日在国网公司招聘平台发布2026年高校毕业生招聘公告（第二批）。

**（二）应聘毕业生投递简历**

1. 填写个人简历。应聘毕业生应通过招聘平台填写个人信息，并上传相关佐证材料，确保信息完整、准确、真实、有效，**相关信息提交后不能更改，请仔细检查后再提交**。具体要求如下：

    （1）生源地填写本科入学前户口所在地（居住地）。

    （2）应聘毕业生应准确填写**最高学历学籍验证码**，教育经历中填写的院校、专业、（预计）毕业时间等信息应与学籍验证报告一致。

    境内院校应聘毕业生应完整上传**各学历阶段**学籍验证报告（学信网下载，PDF格式，并确认在2026年7月1日前有效）；成绩单（加盖公章）；就业推荐表（加盖公章）；就业协议书（网签院校上传学校或学院开具的未就业证明）。

    国（境）外院校应聘毕业生应上传最高学历入学通知书（offer）；最高学历院校成绩单及翻译件（加盖翻译公司公章）；最高学历院校或学院开具的在读证明及翻译件（加盖翻译公司公章）；本科在境外就读的还需上传国家教育行政部门出具的本科学历认证材料，本科在境内就读的需上传本科阶段学籍验证报告。

    （3）如有英语和计算机等级证书、学术论文成果、实践或社会经历（含服役经历），需上传相关佐证材料。

2. 填报应聘单位。招聘公告发布之日起，应聘毕业生可报名应聘国网江苏电力本批次招聘单位，相关信息填报截止时间**2026年3月4日**。

**（三）组织招聘笔试**

1. 国网江苏电力将根据国网公司统一要求组织招聘笔试，时间以国网公司公布时间为准，考察内容详见招聘平台发布的笔试大纲。
2. 应聘毕业生通过资格审查后方可参加笔试，国网江苏电力将通过招聘平台站内消息，通知入围毕业生参加考试，未入围的不再另行通知。
3. **应聘毕业生如收到多个考试通知，需选择其中一个进行确认，确认后按照该单位类型录用要求进行考核，选择提交后将无法更改**。
4. 笔试结束后，考生可登录招聘平台"个人中心"，查询本人笔试成绩。

**（四）组织招聘面试**

国网江苏电力将组织笔试达线人员参加面试，具体安排另行通知。面试主要考察专业基础知识、团队协作意识、组织沟通能力、性格特征、就业意向等。

**（五）公示拟录用人选**

确定拟录用人选后，国网江苏电力将按照规定流程向国网公司申报，待国网公司核准录用人选后的2个工作日内，在招聘平台公示拟录用人选名单，未录用的不再另行通知。

### 四、报名方式

国网公司招聘平台是报名应聘国网江苏电力的唯一渠道，网站地址https://zhaopin.sgcc.com.cn。

### 五、有关要求

（一）应聘毕业生应认真阅读应聘条件，按照要求进行简历的网上投递。本次招聘不接收纸质简历。

**（二）应聘毕业生应保证所填信息完整、准确、真实、有效，字段（含必填和非必填字段）原则上不得漏填**。

**（三）应聘毕业生务必提供准确的联系电话并保持通信渠道畅通**。因填报信息不准确或通信不畅通造成的一切后果，由应聘者本人承担。

### 六、注意事项

（一）因招聘计划有限，国网江苏电力将分单位类型，统筹考虑应聘人数、填报志愿、院校层次、研究方向、在校成绩、资格证书及获奖情况等，择优通知应聘毕业生参加考试。同等条件下，退役军人优先录用。

（二）未上传各学历阶段学籍验证报告和英语、计算机等级证书扫描件（如有），**未准确填写最高学历学籍验证码**，将影响简历筛选结果。

（三）有以下情形之一的，将取消应聘者的相应资格：

1. 应聘过程提供虚假信息的，包含但不限于以下方面：在招聘平台填写的信息不真实或失效的（含入学时间和毕业时间填写错误的）；伪造、涂改各类证书、毕业生推荐表、成绩报告单、学历学位及相关资格证书、获奖证明的；修改毕业院校、所学专业名称，虚报在校成绩信息和获奖荣誉的；隐瞒病史或个人真实情况的，包括身体状况、学习（工作）经历、签约或考研（博）现状等。

2. 在应聘考试过程中作弊或协助他人作弊的。

3. 破坏公司招聘秩序，在网络及其他媒体上造谣生事、发表不实言论的。
