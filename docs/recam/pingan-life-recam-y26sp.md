## 平安人寿简介

- ✅ 中国平安：世界500强，中国500强
- ℹ️ 主要子公司：平安人寿保险（简称：**平安人寿** 或 **平安寿险**）、平安财产保险、平安养老保险、平安健康保险、平安银行、平安证券、平安科技、陆金所，等。

中国平安保险（集团）股份有限公司（简称“**中国平安**”）于1988年诞生于深圳蛇口，是中国第一家股份制保险企业，在各级政府及监管部门、广大客户和社会各界的支持下，中国平安成长为国内金融牌照最齐全、业务范围最广泛的综合金融集团之一， 致力于成为国际领先的综合金融、医疗养老服务提供商。中国平安在香港联合交易所主板（2318.HK ）及上海证券交易所 （601318.SH）两地上市。

平安集团旗下专业公司主要包括以保险、银行、资管为代表的综合金融业务和以平安健康、北大国际医院为代表的的医疗健康业务，涵盖金融、医疗、养老的各个领域。中国平安深化“综合金融+医疗养老”服务体系，提供专业的“金融顾问、家庭医生、养老管家”服务，让客户享有“省心、省时、又省钱”的综合金融、医疗养老消费体验。

## 岗位列表

**1、NS管培生**

NS是 New Star 的意思。管培生全称是“管理培训生”（Management Trainee）。简单来说，可以把它理解为一个为企业储备未来管理人才的“快车道”。

这个概念最初由宝洁等大型外企在80年代末引入中国，本质是企业为了培养未来的领导者，而对应届生进行的专项招聘和孵化计划。

Trainee（培训生/管培生）。（1）身份：你已经毕业了，是公司的正式员工，签的是正式劳动合同。（2）时长：长期的，培训期（编者按：有的公司也称之为试用期）只是你职业生涯的开端。（3）目标：被培养成公司的核心骨干。（4）关系：从一开始，你就是公司的人了。

Intern（实习生）。（1）身份：通常是在校学生，利用寒暑假或课余时间来积累经验的。（2）时长：短期的，几个月甚至几周。（3）目标：体验职场，拿到一个实习证明，表现好有机会留用。（4）关系：你还不算正式员工。

**2、 `(nc)`：not collected 未收录**。 感兴趣同学可查看官网并投递。

## NS管培生（消费者权益）（平安寿险-社区金融服务事业部）

`职位类别：运营类`

**岗位职责:**

1. 组织事业部消费者权益保护相关制度及机制的制定与完善。
2. 总部、事业部消委会要求的各项消保工作的落实和推动，各类材料报送及工作沟通。
3. 制定消费者权益保护年度工作计划和目标，定期向事业部消保工作事务委员会报告消费者权益保护工作开展情况；统筹组织开展事业部消保事务委员会各项工作。
4. 协助组织推动金融知识宣传教育活动，督促相关责任团队落实有关监管要求，主动预防和化解潜在矛盾，提高消费者金融素养。督促和辅导相关责任团队有序开展内部教育和培训，强化员工消费者权益保护意识。
5. 组织推动事业部消保管理体系的搭建及完善。

**岗位要求:**

1. 具备较强的沟通能力，具备一定的数据处理、汇总分析能力；
2. 性格外向，积极主动，，具备优秀团队意识；
3. 逻辑条理性强，善于主动思考复盘；
4. 有保险公司实习经验优先考虑。
