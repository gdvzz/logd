## AI算法工程师（AIGC）
`新国脉数字文化股份有限公司` \| `上海市`

**学历要求：**
- 本科及以上

**专业要求：**
- 计算机科学与技术、人工智能、软件工程、数学与应用数学、自动化等相关专业

**岗位职责：**
1. 负责研发基于Diffusion Models的视频生成算法，提升文本到视频的语义还原度与物理合理性；
2. 负责开发视频时序连贯性优化方案（解决对象变形、运动断层等行业痛点）；
3. 构建多模态控制能力（文本/图像/语音→视频）并集成至公司内容生产平台；
4. 负责跟踪Sora、Stable Video Diffusion等前沿技术，实现工业级效果复现与优化。

**任职资格：**
1. 本科及以上学历、学士及以上学位，计算机科学与技术、人工智能、软件工程、数学与应用数学、自动化等相关专业优先；
2. 精通深度学习框架，熟悉Diffusion Models原理，有视频生成算法相关项目或研究经历；
3. 具备解决复杂技术问题的能力，针对视频时序连贯性问题，能设计并开发有效的优化方案，攻克对象变形、运动断层等行业难题；
4. 有多模态数据处理经验，可构建文本、图像、语音到视频的多模态控制能力；
5. 热爱互联网行业，并关注前沿动态，能快速跟踪Sora等新技术，实现效果复现与优化，推动技术迭代升级。

## 推荐算法工程师
`新国脉数字文化股份有限公司` \| `上海市`

**学历要求：**
- 硕士研究生及以上

**专业要求：**
- 人工智能、计算机科学与技术、数学与统计学、软件工程等相关专业

**岗位职责：**
1. 用户行为预测与个性化推荐​：基于LSTM、Prophet等时序模型开发用户积分消耗预测模型，结合用户消费水平、兑换偏好等画像实现动态商品推荐，提升兑换率；
2. 构建欺诈检测模型：通过异常检测算法Isolation Forest、GNN，实时识别短时高频兑换、跨地域套利等异常兑换行为，集成规则引擎阻断风险交易；
3. 基于BERT+BiLSTM训练意图识别模型处理用户咨询，集成知识图谱实现兑换规则、积分余额等场景的自动应答，降低人工客服负载；
4. 基于Flink+Kafka构建实时特征管道，支持千TPS级兑换请求处理；离线层通过Spark优化历史数据回溯如用户生命周期分析；
5. 开发特征存储平台（Feature Store），自动生成用户画像标签及行为特征；
6. 建立AB测试框架对比模型效果，如推荐点击率、风控召回率，结合MLflow实现模型版本管理与灰度发布。

**任职资格：**
1. 硕士研究生及以上学历、硕士及以上学位，人工智能、计算机科学与技术、数学与统计学、软件工程等相关专业优先；
2. 精通Python/C++，熟练掌握TensorFlow/PyTorch框架；
3. 熟悉经典机器学习算法（SVM、决策树、聚类等）及深度学习架构（CNN/RNN/Transformer）；
4. 具有与应聘岗位相关的实践项目或实习经历；
5. 具有较强的逻辑思维和学习钻研能力；
6. 有AI相关项目经验者优先；
7. 具备技术热情、持续学习能力，对行业趋势敏锐。
