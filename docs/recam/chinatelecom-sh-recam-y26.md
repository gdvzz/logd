### 信网公司

### 宽频公司

上海电信住宅宽频网络有限公司是上海电信的控股公司。根据上海电信宽带业务发展战略的需要，2000年上海电信与上海永高建设有限公司合资成立上海电信住宅宽频网络有限公司。目前公司注册资本5000万元，中国电信股份有限公司控股60%、北京瑞达云讯科技有限责任公司参股20%、上海柏逍信息科技有限公司参股20%。

公司主要转型向社会提供楼宇信息化、智慧照明以及细分领域的智慧服务，着力打造细分行业信息化服务。

### 上海热线

上海热线信息网络有限公司是上海信息产业（集团）有限公司的全资子公司，注册资本2000万元，定位为互联网信息和应用服务专业公司。

上海信息产业（集团）有限公司是中国电信股份有限公司的全资子公司。上海电信以此公司为运作平台及对外投资的出资主体。
公司自成立以来，凭借敏锐的战略发展眼光，始终保持与网络时代同步，快速地获得关注上海、热爱上海的网民的认可，奠定了“上海热线”户网站的地位，并且连续多次位列中国互联网信息中心（CNNIC）组织的中国互联网络发展状况调查十佳网站之列。

## AI项目拓展与交付工程师
`中国电信上海公司` \| `上海市`

**学历要求：**
- 本科及以上

**专业要求：**
- 计算机科学、软件工程、人工智能、信息安全或相关理工科专业，优秀应届毕业生。

**岗位职责：**
1. AI 敏捷落地：使用 Python 及 Agent 工作流（如 Dify/LangChain）快速搭建 AI 应用原型，并根据客户反馈持续调优 Prompt。
2. 复杂数据治理：将客户现场的非结构化脏数据（PDF、复杂表格、日志）进行清洗、结构化提取与向量化处理。
3. 全栈系统集成：编写 API 或脚本，实现 AI 应用与客户业务系统（如OA/ERP/CRM）的无缝打通。
4. 工程化排雷：解决驻场现场的技术卡点，封装高频通用组件，提升团队整体交付效率。

**任职资格：**
1. 编程基础：计算机/软件相关专业，精通 Python/Java/Golang 中的至少一种，具备良好的后端逻辑思维及 SQL 基础。
2. AI 热忱：对大模型（LLM）有浓厚兴趣，了解 RAG 等基础原理，能动手调用 API 实现简单的 AI 功能。
3. 工程潜力：具备较强的任务拆解能力，能够清晰地表述自己的开发思路，有代码整洁与模块化意识。
4. 沟通与素质：具备良好的文档编写与沟通能力，能与客户初步交流；抗压能力强，愿意深入一线参与项目实践。
5. 加分项：有 AI 或软件开发相关实习经历，参与过实验室或竞赛项目者优先。
