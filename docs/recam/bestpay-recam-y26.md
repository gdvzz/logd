## 大数据开发工程师（沪）
`中国电信集团有限公司北京网络安全技术中心` \| `上海市`

**学历要求：**
- 硕士研究生及以上

**专业要求：**
- 计算机、软件工程、数学或相关专业优先

**岗位职责：**
1. 基础设施研发： 参与大数据平台基础架构及核心数据处理链路的研发与日常维护。
2. 计算与分析引擎： 协助开发流计算与批处理任务，参与构建海量数据体量下的在线分析引擎与存储引擎。
3. 架构与业务探索： 深入理解业务需求，参与数据模型设计，在资深工程师指导下协助进行系统性能瓶颈的分析与调优。

**任职资格：**
1. 计算机科学、软件工程、数学或相关专业优先。
2. 综合基础： 具备扎实的计算机基础理论知识（数据结构、算法、操作系统、计算机网络等），熟悉常用的关系型数据库及 SQL 编写。
3. 编程语言： 熟练掌握 Java、C++ 或 Python 中至少一门编程语言，具备良好的面向对象设计思想和代码规范。
4. 大数据与 Flink： 了解主流大数据技术生态（如 Hadoop/Spark/Hive 等）；了解实时流计算的基本概念，对 Apache Flink 有基础的认识或简单的项目使用经验。
5. 综合素质： 具备优秀的逻辑思维能力、强烈的技术好奇心和求知欲，工作踏实严谨，有良好的团队合作精神。

加分项：
1. 在校期间有 Flink/Spark/Doris/ClickHouse 等大数据组件相关的高质量实验室项目、毕业设计或大厂实习经验。
2. 具备 Apache 社区（如 Paimon、Doris 等）开源贡献经验，或有技术博客分享习惯者优先。
3. 对网络安全或数据安全领域有一定基础了解者优先。
4. 关注 AI 大模型等前沿技术发展，日常习惯使用 AI 工具辅助编程与解决问题，或对“数据+AI”应用有一定思考者优先。
