**岗位职责：**
1. 负责针对公司AI相关产品制定合适、完备的测试方案；
2. 负责公司AI相关产品的测试执行工作，包括算法的功能、性能、稳定性等核心指标测试以及AI应用的端到端测试；
3. 负责分析相关AI算法及应用的测试结果，形成测试报告；
4. 负责根据不同AI算法搜集、建立相应测试数据集；
5. 参与相关定制化测试工具的开发和改进工作；
6. 针对AI模型有独立的见解与深入的思考，具备敏锐的观察力。

**任职资格：**
1. 重点院校本科及以上学历，计算机、软硬件开发、人工智能、电子信息、自动化等相关专业；
2. 熟练掌握Python语言，具备编写程序、脚本执行AI智能体和AI模型测试用例的能力，能独立完成从测试用例代码编写到执行、结果分析的全流程；​
3. 熟悉AI基本原理，了解AI模型的训练与推理流程，能理解模型输入输出关系及关键参数含义；​
4. 有AI相关产品测试经验、机器学习模型、AI应用系统测试经验优先；​
5. 思路清晰、严谨细致、拥有快速的学习能力，善于与他人沟通协作。
